  3. main 브랜치의 최상위 index.html을 새 파일로 교체하고 Commit changes를 누릅니다. 파일 이름은 반드시 index.html이어야 합니다.
  4. Actions에서 배포 완료를 확인한 뒤 기존 주소를 새로 고침합니다. 이전 화면이면 Ctrl+Shift+R로 갱신합니다.

아이템 데이터 수정

base: 기본 수치 / levels: 1~5각성 수치. 빈 정보는 null로 유지하세요. acquisition은 확인된 획득처 또는 null입니다. recordedLevels는 원본에 기재된 각성 단계 수입니다. 아이콘은 자동 보존됩니다.

도감 이용 안내

검색은 아이템명, 능력, 수치, 설명, 획득처를 함께 확인합니다. 공백으로 구분한 검색어는 모두 포함되는 아이템을 찾습니다.

아이템을 열면 기본 능력과 각성 1~5단계의 원본 수치를 확인할 수 있습니다. ‘전체 비교’는 같은 능력의 단계별 변화를 나란히 보여줍니다.

‘비교 +’로 최대 3개를 선택해 아이템을 비교할 수 있습니다.

기재 여부를 구분합니다.

원본 미기재: 해당 각성 단계 전체 또는 획득처가 캡처에 없습니다.
변경란 미기재: 각성 단계는 있지만 이 능력의 값은 적혀 있지 않습니다.

미기재를 효과 없음·변경 없음·이전 수치 유지로 해석하지 않습니다. 각성 값은 누적해서 더하지 않으며 원문 표기를 그대로 비교합니다.

분류는 이름 기준 탐색용입니다. 근거리/원거리는 원본에 기재된 항목만 표시합니다. 공식 장비 슬롯이나 등급은 추정하지 않았습니다.
